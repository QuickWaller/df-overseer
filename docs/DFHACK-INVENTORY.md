## What this is, and is not

- **Names, tags and one-line summaries are DFHack's own words.** Nothing here was
  run. "Available" means DFHack does not tag it `unavailable`; it does not mean we
  have used it or that it works headless.
- **"Mentions" counts files** under `research/`, `memory/`, `docs/` and
  `scripts/dfhack/` that contain the tool's name as a whole word. It is approximate:
  common-word names (`sort`, `probe`, `plant`) overcount, and `0` means we have
  never written the name down, not that it is useless.
- **Tags are DFHack's.** `armok` means "god-like powers or access to information the
  game hides", which is the closest thing DFHack has to a cheat marker. The project
  has no written rule about them yet (see `Working.md`).

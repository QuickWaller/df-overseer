  despite its docstring: fixed (progress output, check per target, non-zero
  exit on drift). The two silent VM 103 runs were verified by stamp, service
  start time and file contents.

  and the publisher's site text file: added.
- A publisher tick between code and env changes published the fort under id
  `Uniboslan`; the stray entry and folder were removed from staging and the
  relay.
